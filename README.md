# BOR — антибот для Telegram на Python

**Приоритет первого релиза — защита входа в Telegram-супергруппу.**

Python 3.12 + aiogram 3.31.0, SQLite WAL, Docker, GitHub Actions. Репозиторий отдельный от Rust-репозитория Lalalalendia/bot. [Исходные требования в Notion](https://app.notion.com/p/3ff32a84beec81b6940ec94961d43338).

## Функции первой версии

- Защита **выключена по умолчанию**. Администратор тестовой супергруппы включает её с помощью /guard on.
- При вступлении новичок не может отправлять сообщения до CAPTCHA: пример сложения, **9 кнопок**, **120 секунд** и **3 попытки** (настраивается).
- Если пользователь подаёт заявку на вступление, CAPTCHA отправляется в отдельный временный чат, если Telegram разрешает доставку. Верный ответ одобряет заявку.
- Три неверных ответа или истечение срока приводят к временному исключению из группы (5 минут) либо отклонению заявки. Администраторы и другие боты не ограничиваются автоматически.
- SQLite сохраняет настройки групп, незавершённые проверки и использованные кнопки. Неопределённые результаты Telegram API не повторяются автоматически, а поступают в ручную очередь.
- Команды для администратора: /guard on, /guard off, /status, /pending, /allow ID, /deny ID.
- Команды пользователя: /start, /help, /version. Команда /book demo осталась отдельным демонстрационным примером ссылок, но не является задачей первого запуска.

## Быстрый тест

1. Создайте **тестового** бота через [@BotFather](https://t.me/BotFather). Токен записывайте только в локальный .env или на сервер — **никогда не отправляйте его в чаты или GitHub**.
2. В новой тестовой **супергруппе** добавьте бота администратором. Нужны права **ограничивать участников** и (для режима заявок) **управлять приглашениями**.
3. Скопируйте .env.example в .env и укажите BOT_TOKEN.
4. При наличии Docker Compose: 

~~~bash
docker compose --env-file .env -f compose.local.yml up -d --build
docker compose --env-file .env -f compose.local.yml logs -f bot
~~~

5. Администратор пишет /guard on и /status.
6. **Отдельный тестовый пользователь** вступает в супергруппу, решает CAPTCHA и получает доступ. Проверьте также ошибку, истечение времени и перезапуск.

Чтение прав Telegram без изменения группы:

~~~bash
docker compose --env-file .env -f compose.local.yml run --rm \
  -e BOR_TEST_CHAT_ID=-1001234567890 --entrypoint python bot -m bor.preflight
~~~

Замените ID на реальную тестовую супергруппу, но не публикуйте токен. Если у бота уже настроен webhook, long polling намеренно не запускается.

## Выпуск через GitHub Actions

[Проверки и сборка](.github/workflows/ci-deploy.yml) запускаются на PR и в main. Автоматическое обновление рабочего контейнера **отключено** до отдельной настройки сервера, проверенных SSH-секретов и переменной BOR_DEPLOY_ENABLED=true. [Инструкция развёртывания](docs/deployment.md) описывает ручной первый выпуск и откат. База SQLite хранится в постоянном томе Docker.

## Проверка и текущие ограничения

~~~bash
python -m unittest discover -s tests -v
~~~

Для полного тестирования нужна установленная библиотека aiogram. На начальном этапе это тестовая версия **только защиты при входе**, без антиспама обычных сообщений, жалоб, блокировок по содержимому или анализа изображений. Не давать ей права администратора рабочего сообщества до полного подтверждения сценариев Telegram: членство, заявки, верная/неверная кнопка, срок, перезапуск, запрет API и ручная разблокировка.
